1 · Project Scope (full target per PRD v1.3)

MESA is a biometric-native enterprise canteen platform: one identity, every meal, zero friction. Three-tier architecture — central web admin portal, enrollment module, resilient offline-capable POS client — unified on a single backend. Scope spans 13 product modules (PRD §10), 64 functional requirements (PRD §11), ECDSA P-256 self-contained licensing (PRD §13), and a 3-phase delivery plan (PRD §20).
